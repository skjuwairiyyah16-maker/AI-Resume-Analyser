# AI Resume Analyzer

An AI-powered web application that analyzes resumes and compares them with target job requirements.

## 🚀 Live Demo

https://ai-resume-analyzer-ruddy-gamma.vercel.app

## ✨ Features

- Resume PDF upload
- Resume text extraction
- ATS compatibility score
- Skill matching
- Skill gap detection
- Job role matching
- Dashboard with analysis results
- Scan history
- Resume improvement suggestions

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Chart.js
- PDF.js
- Vercel
